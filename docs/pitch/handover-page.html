What this is

The demo was built for trade-show meetings with group tour operators. The story for a short meeting is an easy process plus visible money: the Trip studio builds a priced, mapped trip in seconds, and the invoice check and profit leaks show where planned profit went and how to recover it.

It is not production code. One offline HTML file, no backend, no logins, simulated payments and accounting sync, and a fictional agency (Redbud Group Tours, Tulsa).

Open it

  • On the web: triplanet-viewpoints-demo.vercel.app. Public, no account needed. It is deployed by hand from the repository's main branch, so it is redeployed after each merge. A copy on claude.ai (link, private until shared) also has the spoken morning brief.
  • Offline: open v6/triplanet-booth.html from the repository in Chrome or Edge. No install and no internet needed.
  • Switch person with "View as" (top bar; in the ☰ menu on phones):
    • Agency team: owner, accountant, operations coordinator, 6 agents.
    • Client side: group leader, traveler.
    • Suppliers and field: supplier, tour director.
  • The gear menu has the guided tour, meeting mode (1, 3 or 10 minutes), Hebrew and English, day and night, and developer notes, which show the specification of the screen you are on.

Build and check

python3 build.py

Builds v6/triplanet-booth.html from the modules in v6/.

node check6.js

About 25 seconds. A clean run shows LEFTOVER 0, bad 0, every TEST … ok, and the unchanged line P rev 950103.7 pp 142334.7 fp 138322.99.

node sweep84.js

Opens every page and portal tab in English and Hebrew, day and night, at desktop and phone width (Playwright). It must report 0 page errors and 0 overflow.

What is in v8.4

Agency

  • Owner command center, accountant money desk, operations readiness board, agent homes.
  • Quotes, Trip studio, itinerary with drag and drop, pricing, proposals in three formats, versions, supplier alternatives.
  • Operations tasks, master list and traveler forms.
  • Finance stage, invoice check and dispute, profit leaks, simulated accounting sync.
  • Maya, the assistant: scripted answers, with typed questions optionally answered live by Claude.

Portals (previews)

  • Group leader: proposal, payments by household, forms, messages.
  • Traveler app: pay, forms, plan, help.
  • Supplier: bookings, rooming lists, invoices and queries (fictional suppliers only).
  • Tour director run sheet: stops, manifest with flags, vouchers, notes.
  • Spoken morning brief on the owner's home (published page, Chrome or the Claude app).

Not included, on purpose

  • The Maya live API key. It lives only in the booth laptop's browser and must never go into the repository or the file.
  • Booth leads. They are stored only on the booth laptop and contain visitors' personal data.
